## Historical archive

Files under [`history/`](history/) are retained as project records and are not current implementation contracts. The archive is grouped by subject:

- [`history/warehouse/`](history/warehouse/) — warehouse designs, implementation notes, status, schema snapshots, and audits.
- [`history/api/`](history/api/) — API handoff material.
- [`history/report/`](history/report/) — reports and follow-up analysis.
- [`history/superpowers/`](history/superpowers/) — dated plans and specifications.

Check the current guide, code, and migrations before relying on historical details.
