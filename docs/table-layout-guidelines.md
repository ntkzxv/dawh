# แนวทางจัด Layout หน้าตาราง

อ้างอิงแถบเครื่องมือจาก `/warehouse/inventory?kind=products` ใน `app/warehouse/inventory/ProductInventorySplitView.tsx` และอ้างอิงกรอบตารางกับ pagination จากหน้า `/test` tab 2 ใน `components/warehouse/TableDesignPlayground.tsx`

หน้ารายการตารางใช้ `components/common/DataTable.tsx` เป็นแหล่ง CSS กลาง โดย `DATA_TABLE_STYLES` กำหนดรูปแบบตาราง, หัวตาราง, แถว และช่องข้อมูล ส่วน `dataTableFrameClassName` กำหนดกรอบ พื้นหลัง และมุมโค้งให้ตรงกับ `/test` tab 2 ส่วน `components/common/Pagination.tsx` ใช้แสดงสรุปและปุ่มเปลี่ยนหน้าในรูปแบบเดียวกัน

## โครงสร้างหน้า

1. วางแถบเครื่องมือเหนือกรอบตารางในแถวเดียวกันเมื่อหน้าจอกว้าง:
   - ซ้าย: ช่องค้นหา ตามด้วยปุ่มตัวกรอง; รวมตัวเลือกกรองไว้ใน dropdown ของปุ่มนี้
   - ขวา: ปุ่มการทำงานอื่นที่หน้านั้นมี เช่น นำเข้า/ส่งออก ตามด้วยปุ่มหลักสำหรับเพิ่มข้อมูลในตาราง เช่น “เพิ่มสินค้า” หรือ “เพิ่มสาขา”
   - จอแคบให้สองกลุ่มตัดบรรทัดได้ โดยคงลำดับช่องค้นหา → ตัวกรอง → ปุ่มอื่น → ปุ่มเพิ่ม
   - ไม่ต้องใส่หัวข้อทั่วไปหรือจำนวนซ้ำเหนือฝั่งซ้ายของตาราง เช่น “รายการทั้งหมด”, “รายการ” หรือ “All items”; ชื่อหน้าใช้ระบุชนิดข้อมูลอยู่แล้ว และจำนวนทั้งหมดแสดงใน pagination ด้านล่าง หากหน้าเดียวมีหลายตาราง ให้ใช้หัวข้อเฉพาะที่ช่วยแยกแต่ละตาราง
2. แสดงข้อมูลในกรอบสีพื้น มีเส้นขอบและมุมโค้ง โดยใช้ `dataTableFrameClassName(isLight)` ครอบตาราง ให้ตารางเลื่อนแนวนอนได้เมื่อความกว้างหน้าจอไม่พอ
3. วาง pagination แยกอยู่นอกกรอบตาราง เว้นระยะจากตารางอย่างชัดเจน
4. แบ่ง pagination เป็นสองฝั่ง:
   - ซ้าย: แสดงหน้าปัจจุบันและจำนวนหน้าทั้งหมด เช่น “หน้า 1 จาก 2” พร้อมจำนวนรายการทั้งหมด เช่น “ทั้งหมด 6 รายการ”
   - ขวา: ปุ่มเปลี่ยนหน้าและหมายเลขหน้า

ใช้รูปแบบกรอบเดียวกันกับทุกหน้าคลังสินค้าที่แสดงข้อมูลเป็นตาราง รวมถึง `/warehouse/inventory` โดยวางแถบค้นหา/ตัวกรองและปุ่มการทำงานไว้เหนือกรอบตาราง ส่วน pagination อยู่นอกกรอบด้านล่าง

## การตอบสนองและพฤติกรรม

- หน้าจอแคบให้เรียงข้อความสรุปและปุ่ม pagination ลงคนละบรรทัด; หน้าจอกว้างให้แสดงในแถวเดียวกัน
- รองรับภาษาไทยและอังกฤษ รวมถึงสีตามธีมสว่าง/มืด
- เมื่อค้นหาหรือเปลี่ยนตัวกรอง ให้กลับไปหน้าแรกเพื่อไม่ให้ค้างอยู่ในหน้าที่ไม่มีผลลัพธ์
- เมื่อเปลี่ยนหน้า ให้แสดงเฉพาะแถวของหน้านั้น และอัปเดตข้อความสรุปให้ตรงกับหน้าปัจจุบัน
- สรุปฝั่งซ้ายแสดงหน้าปัจจุบัน จำนวนหน้าทั้งหมด และจำนวนรายการทั้งหมด; ปุ่มเปลี่ยนหน้าอยู่ฝั่งขวา
- หน้ารายงานที่ใช้ cursor และ API ส่งมาเพียง `hasMore`/`nextCursor` ให้ใช้ปุ่ม “โหลดรายการเพิ่ม” นอกกรอบตาราง เพราะไม่มีข้อมูลจำนวนหน้าหรือจำนวนรายการทั้งหมด
- ตารางสรุปหรือ matrix ที่มีแถวคงที่และไม่ใช่รายการแบ่งหน้า ไม่ต้องเพิ่ม pagination

## ตัวอย่างข้อความ

- ไทย: `หน้า 1 จาก 2 · ทั้งหมด 6 รายการ`
- English: `Page 1 of 2 · Total 6 items`
